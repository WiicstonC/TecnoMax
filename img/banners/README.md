# Banners TecnoMax

Los archivos SVG de esta carpeta son piezas publicitarias vectoriales creadas específicamente para la interfaz de TecnoMax.

- `tecno-banner.svg`: banner principal tecnológico.
- `tablets-accesorios.svg`: banner de tablets y accesorios.
- `accessories-strip.svg`: franja promocional de accesorios.

Las fichas técnicas del sitio usan referencias comerciales reales y la disponibilidad/precio se consulta por WhatsApp para evitar publicar información de inventario no confirmada.
